# Glosario

| Término | Significado |
|---------|-------------|
| CUPE | Código Único de Cliente ELO-XXXXX |
| ELISA | Sistema ERP de ELOMUX |
| ELOMUX | Empresa de desarrollo web y soluciones digitales |
| RBAC | Control de acceso basado en roles |
| JWT | JSON Web Token (autenticación) |
| DRY | Don't Repeat Yourself (principio de no repetición) |
| CUIT | Clave Única de Identificación Tributaria |
| DNI | Documento Nacional de Identidad |
| RUC | Registro Único de Contribuyentes |
| L1-L4 | Niveles de rol con permiso de escritura |
| Staff | Usuario con permisos administrativos |
| Soft Delete | Eliminación lógica (marca is_active=False) |
| Plan | Tipo de contratación: alquiler o venta |
| WebType | Catálogo de tipos de sitio web |
| WebFeature | Catálogo de funcionalidades extra |
| ChangeRequest | Solicitud de cambio sensible con aprobación |
| AuditLog | Bitácora de auditoría del sistema |
