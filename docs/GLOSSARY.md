# Glosario

| Término | Definición |
|---------|------------|
| CUPE | Código Único de Persona ELISA |
| JWT | JSON Web Token — estándar de autenticación |
| RF | Requerimiento Funcional |
| Soft Delete | Borrado lógico (is_active=False) en lugar de eliminación física |
| DTO | Data Transfer Object — esquema de validación Pydantic |
| ORM | Object-Relational Mapping — Django models |
| RBAC | Role-Based Access Control — control de acceso por roles |
